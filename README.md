# KASN
[![DOI](https://zenodo.org/badge/1441487237.svg)](https://doi.org/10.5281/zenodo.23852819)

Kolmogorov-Arnold Sieve Networks for nonparametric estimation and semiparametric inference, introduced in [Abdurahman (2026)](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7390879).

| Folder | Contents |
|---|---|
| `python/` | `kasn` on PyPI (`pip install kasn`) |
| `r/` | R interface via reticulate (`remotes::install_github("samiabd8/kasn", subdir = "r")`) |

Replication code for the paper: https://github.com/samiabd8/SieveKAN

Abdurahman, S. 2026. "Kolmogorov--Arnold Sieve Networks for High-Dimensional Estimation and Inference." SSRN Working Paper 7390879, Toronto Metropolitan University.
